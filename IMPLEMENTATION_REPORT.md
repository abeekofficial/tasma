### Parsers & Deserialization
| File | Purpose |
|------|---------|
| `srt.parser.ts` | Robust algorithm mapping SRT formats (`HH:MM:SS,mmm`) to standard millisecond offsets, including basic HTML tag sanitization. |
| `vtt.parser.ts` | Algorithm handling VTT structures (with or without hours), ignoring `WEBVTT` headers, and isolating WebVTT specific styling tags. |

### Styling & Serialization
| File | Purpose |
|------|---------|
| `ass.serializer.ts` | The bridge between the web timeline and FFmpeg. Dynamically transforms the `SubtitleTrack` object into an Advanced SubStation Alpha (`.ass`) document, strictly mapping hex colors to BGR format and injecting animation tags (`\fad`, `\pos`). |

### Core Operations & Pipeline Integration
| File | Purpose |
|------|---------|
| `subtitle.operations.ts` | Array utilities designed for the web and worker layers: splitting cues, merging nodes, time-shifting, regex replacements, and overlapping validation. |
| `pipeline.builder.ts` | Upgraded with `.addSubtitles()`, cleanly injecting the temporary `.ass` file generated by the serializer directly into the FFmpeg complex filter graph. |

### Architecture Highlights
- **ASS Rendering Strategy:** By universally deserializing all formats (SRT/VTT) into an abstract `SubtitleTrack` format, and universally serializing that track to `.ass` during rendering, we unlock FFmpeg's most powerful text engine. This allows the backend to easily burn rich-text shadows, multi-colored fonts, and frame-accurate pop animations directly into the video stream, far surpassing standard SRT capabilities.
